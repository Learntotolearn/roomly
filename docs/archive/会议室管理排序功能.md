# 会议室管理排序功能

## Core Features

- 会议室排序显示

- 自定义排序值

- 排序字段管理

## Design

为会议室添加sort_order排序字段，支持自定义排序。前端表格显示排序列，添加/编辑会议室时可设置排序值。会议室按排序值升序显示，数值小的排在前面。
