# 前端每分钟触发后端扫描会议过期并群组通知

## Core Features

- 前端轮询触发扫描接口（当前联调已验证，支持改回60秒）

- 后端只扫描active会议，按正常过期逻辑发送Notice“会议已结束”

- 禁用后端过期状态定时任务，避免状态竞争

- 过期判断与 main.go 完全一致（Asia/Shanghai + 结束时间计算）

- 详细逐条日志（检查/end与now/尝试发送/成功或失败/跳过原因）
