# 前端轮询扫描会议过期并群组通知

## Core Features

- 前端每1分钟轮询后端扫描会议过期

- 后台标签页可继续轮询

- 过期会议触发群组Notice（会议已结束）

- 发送会议纪要至当前会议群(DialogID)

- Toast文案与交互优化

- 提示样式：桌面与移动端分别适配（靠右，移动端70vw）
